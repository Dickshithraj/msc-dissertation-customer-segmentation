# Customer Segmentation & Cluster-Based Marketing Notifications

**MSc Data Science Dissertation** — University of Leeds  
Dataset: UCI Online Retail II (`data/raw/raj.xlsx`)

---

## Project Overview

This project applies unsupervised machine-learning techniques to transactional
e-commerce data to discover meaningful customer segments. Each segment is then
used to generate personalised marketing notification strategies.

### Pipeline stages

| Stage | Description | Key module |
|-------|-------------|------------|
| 1 | Data ingestion & cleaning | `src/data_loader.py` |
| 2 | Feature engineering (RFM + CLV) | `src/features.py` |
| 3 | Clustering (K-Means + HDBSCAN) | `src/clustering.py` |
| 4 | Cluster profiling & visualisation | `src/profiling.py` |
| 5 | XGBoost cluster classifier | `src/classifier.py` |
| 6 | Notification rule generation | `src/notifications.py` |
| 7 | Interactive dashboard | `app/streamlit_app.py` |

## Setup

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the full pipeline
python main.py

# 4. Launch the dashboard
streamlit run app/streamlit_app.py
```

## Running Tests

```bash
pytest tests/ -v
```

## Configuration

All tunable constants (file paths, model hyper-parameters, random seed) are
centralised in [src/config.py](src/config.py). Edit that file before running
the pipeline — do **not** hard-code values inside individual modules.

---

## Data

The raw dataset is the **UCI Online Retail II** dataset, split across two
Excel sheets covering 2009-2010 and 2010-2011. It must not be altered in
place; all transformations write to `data/processed/`.
